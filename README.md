## 🚀 Shipped to Production

Closed source work for an EdTech platform operating in the UK and USA.

### Web

**[Smart Practice & Progress Tracker](https://musecool.com/the-muse)** · Next.js
Product site for an AI lesson companion. Interactive 3D device prototype, a playable piano synthesised in real time from oscillators and filters, and device aware download flows with conversion tracking.

**[Tutor Onboarding Platform](https://tutor.musecool.com/)** · Next.js
Dual path tutor signup with Google OAuth, Google Calendar sync through CSRF protected server side token exchange, per day availability scheduling, and QR code onboarding.

**Client Application** · Next.js · app.musecool.com, account required
Lesson booking, Stripe subscription management and progress tracking for students and parents. Passwordless magic link onboarding on a custom NextAuth credentials provider, carrying new clients from a private email link through tutor recommendation, scheduling and Stripe checkout with 3D Secure.

**Partner Storefront** · Next.js · shop.musecool.com, account required
Commerce surface for partner ordering and fulfilment.

**Internal Admin Platform** · Next.js · internal access only
Operations console for user management, lesson and payout oversight, commission configuration and reporting. Includes a Google Maps tutor discovery tool with Places Autocomplete and Geocoding for UK and US postcode search, plus an AI recommendation service using embedding similarity search.

Stripe Connect onboarding with live verification tracking, a native WebView bridge with two way JavaScript messaging, and a resumable chunked audio upload queue with retry, backoff, and crash recovery.
